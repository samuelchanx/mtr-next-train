# MTR 下一班車 · MTR Next Train (Web)

**Live MTR next-train arrivals for every line and station — in any browser, with no app to install.**

🔗 **Use it now:** [https://samuelchanx.github.io/mtr-next-train/](https://samuelchanx.github.io/mtr-next-train/)

港鐵實時班次查詢網頁版：揀線路 → 揀車站 → 即睇兩個方向嘅下一班車（連月台同到站時間）。免費、免註冊、免安裝 App。

## Why this exists

MTR publishes real-time next-train data as an open dataset on [data.gov.hk](https://data.gov.hk/tc-data/dataset/mtr-data2-nexttrain-data) — but the only consumer-friendly way MTR lets you actually see it is inside the **MTR Mobile app**.

I had no intention of installing an extra app just to check when the next train is coming. The data was already public, so I built the web app myself.

This is it: pick a line → pick a station → see every upcoming train for **both directions**, with platform numbers and arrival times. Zero backend, zero tracking, one static page.

## Features

- All 10 MTR heavy-rail lines — Airport Express, Tung Chung, Tuen Ma, Tseung Kwan O, East Rail, South Island, Tsuen Wan, Island, Kwun Tong, Disneyland Resort
- Both directions per station, every platform, up to 4 upcoming trains each
- 「到站」 pulsing badge when your train is pulling in
- Auto-refresh every 30 s (API-friendly) with a visible countdown, plus manual refresh
- Service-disruption banner and special-service-arrangement notices
- Interchange shortcuts at multi-line stations (e.g. 九龍塘 → 觀塘線)
- Bookmarkable deep links (`#line=TML&sta=TUM`) and remembers your last station
- 繁體中文 + English, dark mode, mobile-first

## How it works

- A single static page: vanilla JS, no dependencies, no build step, no backend
- Calls the data.gov.hk endpoint (`getSchedule.php`) **directly from the browser** — the API sends `Access-Control-Allow-Origin: *`, so no proxy is needed
- Station/line reference data is pre-generated from MTR's `mtr_lines_and_stations.csv` into a static `data.js`; each direction's terminus is derived from the CSV's up-track/down-track sequences (API `UP`/`DOWN` = CSV `UT`/`DT`)
- Handles the API's documented edge cases: rate limiting (HTTP 429), request timeouts, "data absence" responses (`curr_time: "-"`), and station-suspension errors

## Run it locally

```bash
git clone https://github.com/samuelchanx/mtr-next-train.git
cd mtr-next-train
python3 -m http.server 8000
# open http://localhost:8000
```

Station data lives in `data.js`, generated by `build_data.py` from `mtr_lines_and_stations.csv` (a snapshot of [MTR's open-data CSV](https://opendata.mtr.com.hk/data/mtr_lines_and_stations.csv)). To refresh the data: re-download the CSV, then run `python3 build_data.py`.
